ПРАВИЛА, КОТОРЫЕ ЛОМАТЬ НЕЛЬЗЯ
- Деньги только Decimal, 2 знака; количества 3 знака.
- Остатки меняются только документом движения и только в транзакции.
- Каждый запрос к данным компании проверяет принадлежность пользователя компании, на это есть тест.
- Доступ к API — через requirePermission, матрица прав живёт в справочнике БД.
- Все тексты интерфейса — в messages/ru.json и messages/kk.json.
- Телефоны и БИН не пишутся в логи целиком.
- Внешних вызовов нет: SMS, реестр БИН, уведомления, онлайн-касса, платёжный шлюз, ЭЦП и
  мониторинг — моки с интерфейсом настоящих, ключи подключаются переменными окружения.
- Новые зависимости — только с объяснением в коммите.
- Открытые вопросы ТЗ не решай сам: помечай TODO(open-question) и дописывай в docs/TZ-demo.md раздел 8.

КАК ПРОВЕРЯТЬ
  npm run typecheck && npm run lint
  npm test            # vitest: логика и интеграция с базой
  npm run test:e2e    # playwright, 375 px и 1280 px
  npm run build
npm test и npm run test:e2e используют одну тестовую базу — запускай по очереди, не параллельно.
Каждый новый кусок логики закрывай тестом, включая проверку изоляции между компаниями.

ГРАБЛИ, НА КОТОРЫЕ Я УЖЕ НАСТУПАЛ
- Новая таблица со ссылкой на products, companies или documents ломает чистку тестовой базы:
  добавь удаление в tests/helpers/test-db.ts в правильном порядке, иначе падает весь набор
  на нарушении внешнего ключа.
- Телефоны в тестах только формата +77XX…: нормализация не принимает +780…
- testPoolBin(index) — пул на 1000 записей, занятые диапазоны ищи поиском по tests/.
- Новый раздел в шапке требует добавить путь в union NavItem в src/components/app-header.tsx,
  иначе typedRoutes не собирается.
- eslint ругается на <a href="/api/..."> без параметров: делай href шаблонной строкой.
- Кириллица в имени скачиваемого файла — только через filename*=UTF-8'' (RFC 5987).
- npm run db:migrate иногда ждёт ответа в TTY: если висит, запускай через expect.
- Замеры производительности в тестах делай по медиане и после ANALYZE: на общей машине
  единичный выброс ничего не значит.
